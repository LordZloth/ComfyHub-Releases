# Comfy Hub

Your Steam, Battle.net, Xbox and local games in one Steam-style launcher, with a combined store, friends & chat, play time and an addon manager.

## Install

1. Open the [latest release](https://github.com/LordZloth/ComfyHub-Releases/releases/latest) and download **ComfyHub-Setup-x.y.z.exe**.
2. Run it. Windows may say "Windows protected your PC" because the installer isn't code-signed: click **More info → Run anyway**.
3. In Comfy Hub, open **Settings → Connections** and switch on the platforms you use, then sign in to them yourself. Nothing of anyone else's is included.

No admin rights needed. Comfy Hub updates itself: when a new version is out you'll see **Update ready — Restart** at the top.
